# Arsip (JANGAN dibaca kecuali pemilik memintanya)
Dokumen di sini sudah selesai dipakai dan hanya untuk sejarah. Membacanya memboroskan konteks.
- `RENCANA_FITUR.md`, `RENCANA_FITUR_101-1000.md` — daftar rencana fitur 1–1000 (gelombang sudah dikerjakan).
- `PROGRES_FITUR.md` — catatan progres per gelombang.
- `FITUR.md` — daftar fitur kecil lama.
Untuk mencari apakah fitur X sudah ada: `grep -n "kata" docs/arsip/*.md`, jangan buka utuh.
