# Animation Rules

Semua frame dalam satu animasi harus mempertahankan:

- identity
- silhouette
- palette
- proportions
- clothing
- equipment
- facial features

Yang boleh berubah:

- pose
- limb position
- body offset
- hair movement
- squash/stretch
