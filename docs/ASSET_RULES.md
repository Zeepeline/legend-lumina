# Asset Creation Rules

1. Setiap asset harus memiliki:
   - asset_id
   - category
   - size
   - palette
   - material
   - lighting
   - animation requirement

2. Agent tidak boleh mengubah global art style.

3. Agent boleh menciptakan variasi bentuk,
   tetapi tidak boleh mengubah:
   - pixel language
   - lighting direction
   - outline philosophy
   - global color philosophy
   - character proportions
