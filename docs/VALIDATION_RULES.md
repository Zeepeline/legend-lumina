# Asset Validation

Every generated asset MUST be checked against:

[ ] No anti-aliasing
[ ] No pure black outline
[ ] Light source = top-left
[ ] Shadow = cool teal family
[ ] Highlight = warm yellow family
[ ] Correct dimensions
[ ] Correct pixel density
[ ] Correct silhouette
[ ] Correct palette
[ ] Correct perspective
[ ] No unwanted background
[ ] No cropping
[ ] No missing pixels
[ ] No extra objects
[ ] No text
[ ] No watermark

CRITICAL FAILURE

Jika salah satu berikut terjadi:

- asset ter-crop
- background salah
- outline hitam
- anti-aliasing
- perspektif salah
- ukuran salah

→ REJECT

Asset tidak boleh masuk game.
