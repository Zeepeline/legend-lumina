# Legenda Lumina

Action RPG pixel art untuk browser, dibuat dengan Phaser 3.

## Main

- **Tanpa instalasi:** buka `dist/game.html` (satu file, klik dua kali).
- **Dari kode sumber:** jalankan `python3 -m http.server 8000` di folder ini, lalu buka `http://localhost:8000`.

## Ubah kode

- Edit file di `src/` (satu file per fitur, lihat `AGENTS.md`).
- Setelah selesai, jalankan `python3 tools/bundle.py` untuk memperbarui `dist/game.html`.

## Dokumen

- `AGENTS.md`: peta file & aturan untuk AI agent/developer.
- `docs/ART_BIBLE.md`: aturan gaya visual.
